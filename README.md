# Colive Fukuoka 2026 Venue Map

World Nomad Conference / Ikigai Academy at THE LUIGANS Spa & Resort.

Public: https://venue-map.colivefukuoka.com/ (Guest map only)
Edit: https://venue-map.colivefukuoka.com/edit/ (Guest + Staff, login required)

## How to publish pin changes

Step 1. Open /edit/, adjust pins, then press Confirm version and Download public data.
Step 2. Replace assets/map-data.js in this repository with the downloaded file and commit to main.
Step 3. Vercel deploys automatically (project: venue-map).

## Notes

Print uses A4 landscape, one page per date.
Do not commit server-auth files or the baseline PPTX here.
